# Khayrat EPC 工程日报分析系统

面向伊拉克 Samawah **Khayrat 3,200 TPD 水泥粉磨站 EPC 项目**的本地化日报分析原型。系统默认不显示虚构项目数据；导入真实日报后才计算指标。内置数据仅用于演示，并始终显示“示例数据模式”。

## 启动

```bash
python3 -m http.server 4173
```

访问 <http://localhost:4173>。由于使用 ES Modules，不能直接双击 `index.html`。

## 已实现功能

- 导入 UTF-8 CSV 和标准 `.xlsx` 文件（读取首个工作表），支持多文件合并与重复记录去重。
- 按截止日期、车间、工序筛选，并按日报、周报、月报聚合趋势。
- 计算计划/实际平均进度、偏差、当日及累计混凝土、人员构成与环比变化。
- 展示主要设备的发运、到货、安装准备状态，以及日报风险和进度滞后风险。
- 识别连续停工并保留日报名称、日期和原始记录证据。
- 导出当前筛选范围的标准化 CSV，并提供中文字段模板。
- 数据只在当前页面内存中处理，不上传服务器。

## 输入数据结构

CSV 首行或 Excel 首行是字段名。支持以下中文名，也支持代码中定义的英文别名：

| 字段 | 类型 | 说明 |
|---|---|---|
| 日报名称 | 文本 | 证据来源名称 |
| 日期 | `YYYY-MM-DD` | 必填 |
| 车间、工序 | 文本 | 对比和停工识别维度 |
| 计划进度、实际进度 | 数值 | 百分数，可写 `23.5` 或 `23.5%` |
| 当日混凝土、累计混凝土 | 数值 | 单位 m³ |
| 中方人员、属地人员 | 整数 | 现场人员数量 |
| 设备名称、设备状态 | 文本 | 如已发运、已到货、安装准备中 |
| 风险制约 | 文本 | 影响施工或安装的风险 |
| 工作状态 | 文本 | 如施工中、停工、完成 |
| 原始记录 | 文本 | 用于证据追溯的日报原文 |

字段标准化与别名映射位于 `src/analytics.js`，文件解析器采用适配器结构。新增 PDF 或 Google Drive 来源时，只需实现返回行对象数组的适配器，再进入同一标准化和分析流程。

## 计算口径

- **总体进度**：筛选范围内，每个“车间 + 工序”的最新有效记录等权平均；没有值时显示空状态。
- **人员数量**：同一日期各日报记录中的最大中方/属地人数，避免一个日报内多工序重复累加。
- **当日混凝土**：最新日期按“日报 + 车间 + 工序”去重后求和；累计值取筛选范围内最大有效累计值。
- **关键节点滞后**：最新实际进度比计划进度低至少 5 个百分点。
- **连续停工**：同一“车间 + 工序”连续至少 **3 个有效日报日**满足以下任一条件：工作状态明确含“停工 / stopped / suspended”；或当日混凝土为 0 且实际进度与上一有效日报相同。这里的“连续”指连续上报记录，不推断缺失日期。每条命中记录保留日报名称、日期和原始记录。

## 项目时间基准

- 实际现场施工起点：**2026 年 3 月**。
- 合同工期起算：**2026 年 9 月 7 日**。
- 主要设备安装目标：**2026 年 12 月**。

三个日期在界面和语义中相互独立，不将前期现场施工误作合同工期起算。
